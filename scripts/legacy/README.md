# legacy/ —— 第一代脚本（保留原样，仅供追溯）

这里的两个文件是本仓库最早的两份**一次性脚本**，为「德国 2399 → 荷兰」单个任务手写的：

| 文件 | 说明 |
|---|---|
| `fill_nl_2399.py` | 把映射表、荷兰语文案、写出逻辑全写死在一个文件里；用 openpyxl 直接保存（会丢图片、改 sharedStrings） |
| `fill_nl_2399_v2.py` | 同上的改写版，仍为单任务专用 |

它们**不要再用**：现在的做法已经把它们的能力拆成可复用组件——

- 映射：`config/*.json`（按属性名，不写列号）
- 取值翻译：`reference/vocab_de_eu.tsv` + `scripts/vocab.py`
- 写入：`scripts/fill.py`（XML 手术，不破坏模板）
- 体检：`scripts/check.py`

保留的原因：对应一次真实交付（荷兰站 21 行 1568 格，逐格 0 差异、枚举 0 越界），可作对照样例看「从硬编码到配置化」的演进。
